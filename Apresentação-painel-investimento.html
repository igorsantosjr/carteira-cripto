Painel de Investimentos

Um painel próprio pra acompanhar minha carteira de criptoativos, dados meus, no meu GitHub, sem depender do app de nenhuma corretora.

construído com Claude Python + GitHub Actions app instalável (PWA)
Igor Santos · agosto de 2026
o motivo

Por que construir isso?

Apps de corretora mostram só o que está dentro deles — e cada corretora tem o dado de um pedaço da carteira. Eu queria uma visão única, com histórico de verdade, sem instalar nada de terceiro nem depender de anúncio.

01

Visão única

Todos os ativos, de qualquer corretora, num só lugar — editável por mim.

02

Histórico real

Guarda o patrimônio de cada dia — não só o "agora", como a maioria dos apps mostra.

03

Sem terceiros

Roda no meu GitHub, com meus dados — nenhuma empresa vê minha carteira.

04

Automático

Depois de configurado, não preciso abrir nada — ele se atualiza sozinho.

automação diária

O que acontece todo dia às 10h

Clique em cada etapa da linha do tempo.

10:00

GitHub Actions dispara sozinho

Um agendamento (cron) no repositório acorda o robô todo dia, sem eu precisar abrir nada.

10:00

Busca as cotações reais

Consulta CoinGecko e Crypto.com pros preços dos ativos, e o câmbio USD/BRL em fontes públicas — com reservas caso uma falhe.

10:01

Recalcula tudo

Patrimônio total, rentabilidade por ativo, composição da carteira, e os alertas (concentração acima de 70%, queda acima de 10% no dia).

10:01

Grava o histórico do dia

Guarda o patrimônio de hoje na lista de histórico — é isso que constrói os gráficos de evolução semanal e mensal.

10:02

Publica o painel novo

Faz commit do index.html atualizado — o GitHub Pages publica sozinho em seguida.

10:03

Tarefa agendada do Claude entra em ação

Uma segunda automação, independente, busca os mesmos dados atualizados no GitHub e gera um relatório visual complementar.

10:04

Notificação no celular

Essa tarefa agendada me manda uma notificação push com o resumo do dia — sem eu precisar abrir o painel pra saber como estou.

demonstração

No desktop

O painel inteiro roda como uma página estática — abre em qualquer navegador, sem login, sem app.

  • Patrimônio, rentabilidade e variação do dia em destaque
  • Tabela de posições com peso de cada ativo na carteira
  • Checklist automático de alertas de risco
  • Gráfico de evolução semanal e mensal
demonstração

No celular, como app de verdade

Vira um app instalável (PWA) — ícone próprio, tela cheia, sem barra de navegador.

  • Funciona offline, mostrando o último painel salvo
  • Ícone desenhado especialmente pro projeto
  • Instala direto do navegador, sem loja de apps
  • Mesma base de código do painel do desktop
